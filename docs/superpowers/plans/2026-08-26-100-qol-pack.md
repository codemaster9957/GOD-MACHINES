# GOD MACHINES 100 QoL Pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship exactly 100 low-risk quality-of-life improvements across workshop input, quick swap, trading, combat awareness, accessibility, and client reliability.

**Architecture:** A canonical shared manifest defines the exact feature count and defaults. One new general client controller owns overlays/accessibility/command palette while the existing focused client adapters receive only the QoL behavior that belongs to their current responsibility. Gameplay authority remains unchanged.

**Tech Stack:** Roblox Luau, Rojo project layout, Python static contract tests.

**Spec:** `docs/superpowers/specs/2026-08-26-100-qol-pack-design.md`

## Global Constraints

- Exactly 100 unique feature IDs.
- Category budget must remain Workshop 25, QuickSwap 15, Trade 20, Combat 15, Accessibility 20, Reliability 5.
- No client-side inventory, ownership, damage, trade commit, or save authority.
- Existing server remotes/rules remain authoritative.
- Preferences use `GMQoL_` player attributes and are session-local.
- Missing optional UI must fail soft.
